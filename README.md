# Smart Hostel Management System (Java 21 Console Application)

A complete, production-ready, clean-architecture console application built using **Java 21**, **Maven**, **JDBC**, and **MySQL 8+**.

## 📌 Project Overview
The Smart Hostel Management System automates all administrative and student operations in a university hostel setting. It features smart algorithmic modules for lost & found item matching, mess meal demand prediction, room recommendations, automated complaint priority assignment, and food waste management.

---

## 🛠️ Technology Stack
* **Language**: Java 21
* **Build System**: Maven 3.9+
* **Database**: MySQL 8.0+
* **Database Driver**: MySQL Connector/J (`com.mysql:mysql-connector-j:8.3.0`)
* **Testing Framework**: JUnit 5 & Mockito

---

## 🚀 Key Features

### Admin Roles & Capabilities
1. **Student Management**: View and inspect registered student details.
2. **Room Management**: Add rooms, search rooms, inspect occupancy, view room recommendations.
3. **Room Allocation**: Allocate students to available rooms with over-allocation capacity guards (ACID transactions).
4. **Waiting List**: Manage student room upgrade queues.
5. **Leave Management**: Review, approve, or reject student leave applications with remarks.
6. **Complaint Management**: View issues sorted by calculated priority (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`) and update resolution status.
7. **Medical Management**: View medical requests, assign doctors, and update medical treatment status.
8. **Fee Management**: Create fee records, record student payments, view total paid and remaining balances.
9. **Notice Management**: Publish notices with automatic expiration handling.
10. **Smart Lost & Found**: Inspect item matches generated by the similarity algorithm, verify matches, and mark items as returned.
11. **Mess Management**: View real-time meal attendance and run statistical meal demand forecasts.
12. **Food Waste Management**: Track meal preparation vs consumption with automatic waste percentage calculation.
13. **Reports & Analytics**: Comprehensive dashboard overview of occupancy rates, open complaints, pending leave applications, and unpaid fee balances.
14. **Notifications**: Send and view administrative notifications.

### Student Roles & Capabilities
1. **View Profile**: Inspect student profile data.
2. **Update Profile**: Update phone, email, and emergency contact details.
3. **View Room**: Inspect current room assignment, block, floor, and monthly rent.
4. **View Roommates**: Inspect details of active roommates sharing the room.
5. **Apply for Leave**: Submit leave requests with automatic date validation (start date $\le$ end date).
6. **View Leave Status**: Track approval status of leave applications.
7. **Submit Complaint**: Submit complaints with severity rating; system automatically assigns priority score.
8. **View Complaints**: Track resolution status and warden notes.
9. **Submit Medical Request**: Request medical help with urgency classification.
10. **View Fees**: Check fee code, total amount, paid amount, remaining balance, and due dates.
11. **View Notices**: View active notices.
12. **Smart Lost & Found**: Report lost/found items and view similarity matches.
13. **Smart Mess**: Mark meal attendance (`YES`/`NO`) for Breakfast, Lunch, and Dinner (with duplicate attendance guards).
14. **Notifications**: View and mark notifications as read.

## 🧮 Core Algorithms

### 1. Smart Lost & Found Matching Engine
Calculates a 7-attribute weighted similarity score (0–100%):
* Item Name (20%)
* Category (20%)
* Description (20%)
* Color (15%)
* Brand (10%)
* Location (10%)
* Date Proximity (5%)

### 2. Smart Mess Meal Demand Prediction Engine
Calculates a weighted moving average over historical attendance records for the target day of week and meal type:
$$\text{Weighted Average} = (0.50 \times \text{Day}_1) + (0.30 \times \text{Day}_2) + (0.20 \times \text{Day}_3)$$
Adjusted by current hostel occupancy ratio. Displays *"Insufficient historical data for reliable prediction"* when data points are missing.

### 3. Food Waste Calculation
$$\text{Waste Percentage} = \left(\frac{\text{Prepared Headcount} - \text{Actual Attendance}}{\text{Prepared Headcount}}\right) \times 100$$
Calculates remaining headcount and portion waste in kg automatically.
